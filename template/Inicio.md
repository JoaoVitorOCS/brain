## Como usar
- Abra uma conversa do Claude Code na pasta de um projeto: ele já começa sabendo onde você parou.
- `/brain:fechar` no fim do trabalho · `/brain:decisao` quando escolher um rumo · `/brain:lembrar` para um fato que deve durar.
- `/brain:revisar` decide o que do diário (`inbox/sessoes/`) vira nota. `/brain:conectar` liga uma pasta nova.
- `INDEX.md` é gerado: não edite à mão.
