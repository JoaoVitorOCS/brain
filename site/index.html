Instalar o Brain

Um cérebro externo para o Claude Code. Suas notas em markdown, por área da vida; cada projeto com Status e Decisões. Toda conversa nova já começa sabendo onde você parou, e cada sessão vira um diário que você revisa. Tudo fica no seu computador.

Abra este link no computador

O Brain roda no Claude Code, que fica no computador. Mande este link para você e abra lá.

Passo 1

Ter o Claude Code

Já usa? Pule para o passo 2. Se não, cole no terminal e depois rode claude e faça login (precisa de uma assinatura do Claude):

curl -fsSL https://claude.ai/install.sh | bash
irm https://claude.ai/install.ps1 | iex

Passo 2

Instalar o Brain

O botão abre o Claude Code com o comando já digitado. Confira e aperte Enter.

Instalar no Claude Code
Não abriu nada?

O botão passa a funcionar depois que você manda a primeira mensagem no Claude Code. Ou cole estes dois comandos dentro do Claude Code:

/plugin install brain --marketplace JoaoVitorOCS/brain

Só o /plugin marketplace add não basta: ele cadastra o catálogo, mas não instala o plugin.

Passo 3

Configurar

Numa conversa nova do Claude Code (ou depois de /reload-plugins), digite. O nome do plugin vem antes dos dois-pontos:

/brain:setup

Em uns 5 minutos: escolhe onde fica o cofre e as suas áreas da vida, marca as pastas onde você mais usa o Claude Code e pronto. A próxima conversa num projeto já abre com o resumo de onde você parou. No fim do trabalho: /brain:fechar.

Recomendado: quando ele perguntar, siga com o Graphify. É um mapa do código (grátis, local) que faz o Claude consultar o mapa em vez de abrir arquivo por arquivo: em projeto grande, cada pergunta gasta dezenas de vezes menos tokens. Depois, /brain:medir mostra quanto você economizou.
